# 全文上下文与词法RAG对照评测（完整30对API日志）

**项目属性：** 独立模拟项目，2026-10-26。两份虚构员工政策文件。
**模型：** `qwen3.7-plus`；北京地域API；`enable_thinking=false`，`max_tokens=512`；每题分别独立调用一次，未固定temperature（API默认）。  
**对照：** ① 将指定文档完整提供给模型；② 将指定文档切成按章节可引用片段，中文字符二元组BM25检索 `top-k=5`，仅把检索结果交给模型。提示词SHA256和源文件SHA256在完整30对记录中一致；两组输入文本格式并非完全相同。

此外TC033的RAG回答存在小排版笔误（“V0.版本”），不影响拒答及引文的实质正确性。评分为Pass，并在备注留痕。

### 错误归因

本次RAG全部30条均有5个检索片段；对上述关键失败案例，**正确条款已被检索到**，因此TC028的问题位于生成答案的条件一致性判断，而不是检索阶段遗漏证据。对答案正确且检索命中参考条款的案例，不宜把最终通过直接等同于检索召回率经严格测定；本次没有全面标注片段级相关性真值或计算正式Retriever Recall@k。

## 四、评测设计与可复现性

- 30条正式Benchmark（TC005—TC034），另有4条用于设计评分的Pilot；按五类每类6条。
- 两份模拟知识库，固定文件SHA256；同一问题、同一模型标识、同一系统提示词和非思考参数，在30对API日志中已匹配。
- 全文日志：`outputs/public_runs/qwen_20261026T041501Z.jsonl`（TC005，1条）、`qwen_20261026T041845Z.jsonl`（9条）和 `qwen_20261026T043711Z.jsonl`（20条）。
- RAG日志：`outputs/public_runs/rag_20261026T052311Z.jsonl`（30条），包含所检索片段及其BM25分数、回答、使用量和耗时；已删除可能的提供商请求标识。
- 评分：`outputs/scoring_benchmark_30.csv`、`outputs/scoring_rag_30.csv`；逐题Token对照 `outputs/paired_comparison_30.csv`。
- 离线复核：运行 `python scripts/07_summarize_comparison.py`，可复算上述数量并校验30对API日志与逐题Token对照表；无需API Key或额外Python包。

## 五、局限与下一步

1. 只有两份非常短的模拟文件，每题检索top-5（KB-001仅8个章节片段、KB-001+KB-002共15个），该RAG实验尚不能说明在大型企业知识库下的检索扩展性能。
2. 检索使用**基于字符二元组的BM25词法搜索**，没有Embedding、向量库、重排序、权限控制或正式上线部署；不应称为生产级RAG。
3. 一题各仅运行一次、未固定采样temperature；没有稳定性估计、置信区间或因果结论。
4. 评分由AI辅助完成，缺少真正独立的人工复核及一致性指标；核心错误案例应由第二评定者盲审。
5. 问题和检索参数来自开发测试集，尚无独立保留集。现有产品改进PRD属于下一步假设，并未实施和验证。
