# AI Knowledge Assistant Evaluation — 首轮基线结果

**日期：** 2026-10-26  
**性质：** 独立自建模拟企业知识库评测项目；与任何真实企业无合作或委托关系。  
**模型：** `qwen3.7-plus`，北京地域兼容接口；`enable_thinking=false`，`max_tokens=512`，其余采样参数API默认。  
**范围：** Benchmark TC005—TC034，共30例；Pilot TC001—TC004不计入指标。  
**任务：** 给定完整、可控的模拟制度文档回答员工问题；属于 *context-grounded QA*，不是RAG检索效果测试。

## 三、调用和数据溯源

- 30条可审计调用合计输入 **21,028** Token，输出 **4,142** Token，总计 **25,170** Token（含TC005）。
- 本轮没有记录单题端到端延迟；不可报告Latency平均值。
- 评测集先设计了10条正式题（TC005—TC014），再观察这批答案后新增20条题（TC015—TC034）。
- Pilot网页Qwen Chat“自动”模式与API关闭思考模式不是同一条件。

## 四、固定Rubric（可复核）

- **Factual Correctness：** 所有与题目相关的实质性结论必须正确且限定得当；明确错误、自相矛盾或无依据确定性断言为Fail。
- **Citation Correctness：** 所引用文档编号、章节应存在且相关；伪造章节或错误归属为Fail；纯无答案且不需要条款支持可记N/A。
- **Answer Completeness：** 覆盖问题明确询问的要点；不要求加入未被提问的所有制度细节。
- **Groundedness：** 实质性断言能够从允许的文本推出，或者恰当地说明无法确定；不能把某一条款的规则迁移到另一条款。
- **综合通过：** 四项均Pass。这里没有通过“自动模型裁判”替代独立人工复核，也没有双人信度估计。

## 五、局限与后续验证

1. 模拟知识库只有两份短文档，完整放入上下文，未评估向量检索、重排、召回、chunking或动态数据更新。
2. 每题只运行一次；无法推断重试稳定性、模型间优劣或统计显著性。
3. 标准答案与部分题目经过前期试测迭代，且后一批题目是在观察前一批输出后设计，存在开发集依赖和评审者偏差风险。
4. 四维指标不等价于生产系统整体安全性；后续应建立独立保留集、双人审核及明确的版本更新记录。
5. 真实PRD优化效果尚未验证，后续报告必须将“已观测问题”与“拟议方案”分开。

## 六、可迁移的产品改进方向（待验证）

- 为关键规则抽取“适用场景—条件—结论—限定词—来源”结构化证据，减少跨规则外推。
- 输出前验证引用文档编号和实际存在的章节，降低虚构位置。
- 对逐项审查任务，验证列表判断与最终结论的逻辑一致性。
- 针对“超过、至少、原则上、当前有效”等限定词设计配对回归测试。
